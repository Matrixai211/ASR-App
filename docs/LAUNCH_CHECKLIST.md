# Launch checklist

- Configure production PostgreSQL and migrations
- Add authentication and role authorization
- Configure private audio/artwork object storage and CDN
- Add malware/file validation and audio metadata processing
- Configure payment processor, mobile money/card methods and signed webhooks
- Implement royalty/ledger accounting before payouts
- Configure email and transactional notifications
- Add copyright/takedown and dispute operations
- Finalize privacy, distribution, commerce and platform terms with counsel
- Add monitoring, backups, rate limits and abuse controls
- Test artist upload → moderation → publish → playback end to end
- Test subscription lifecycle and failed payment handling
- Load/performance test streaming infrastructure
