# ASR App

ASR (African Sound Revolution) is a distribution-first music platform combining streaming, artist distribution and direct music commerce.

## Included in this starter
- Artist Studio
- Release creation workflow
- Streaming product foundation
- Free + Premium subscriptions
- Downloads/store
- Merch and tickets
- Advertising
- Label services
- Admin/moderation architecture
- `/api/health` endpoint

## Stack
Next.js App Router + TypeScript. PostgreSQL persistence, object storage, authentication and payment integrations are the next implementation layer.

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000 and test GET /api/health.
